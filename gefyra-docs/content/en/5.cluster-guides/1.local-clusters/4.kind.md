## Prerequisites
1. Follow the [installation](/en/quickstart/installation) for your preferred platform.
2. Create a local Kubernetes cluster with `kind` like this: Create a file `kind-config.yaml`:

```yaml
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
- role: control-plane
  extraPortMappings:
  - containerPort: 31820
    hostPort: 31820
    protocol: udp
```

Run:

```bash
kind create cluster --config kind-config.yaml
```

## Running Gefyra

### 1. Set up Gefyra with

```sh
gefyra up
```

### 2. Run a local container with Gefyra (Zero Image Build)

No image build or repository clone is required. Run an official Python container from Docker Hub:

```sh
# 1. Create a local response file
mkdir -p /tmp/local-server
echo "<h1>Hello from Gefyra. Live local code served directly into kind!</h1>" > /tmp/local-server/index.html

# 2. Run the local container in Gefyra
gefyra run \
  -i python:3.12-alpine \
  -N mypyserver \
  -v /tmp/local-server:/app \
  -c "python3 -m http.server 8000 -d /app" \
  -d
```

### 3. _Exec_ into the running container and verify cluster access:

```sh
docker exec -it mypyserver sh
wget -O- hello-nginx
exit
```

will print out the website of the cluster service hello-nginx from within the cluster.

### 3. Mount the workload and create a bridge to intercept traffic with your local container:

Mount the cluster deployment with Carrier2:

```sh
gefyra mount create --target deployment/hello-nginxdemo/hello-nginx --name mymount
```

Next, create the bridge connecting your local container to the mount:

```sh
gefyra bridge create --mount mymount -p 80:8000 -t mypyserver --match-path-prefix /
```

Check out the locally running server comes up under: [http://hello.127.0.0.1.nip.io:8080/](http://hello.127.0.0.1.nip.io:8080/){target="_blank"}

### 4. List active bridges and mounts:

```sh
gefyra bridge list
gefyra mount list
```

### 5. Remove the bridge and restore the cluster:

```sh
# Delete the bridge
gefyra bridge delete <bridge-id>

# Unmount the workload and restore original container image
gefyra mount delete mymount
```

Check out the initial response from: [http://hello.127.0.0.1.nip.io:8080/](http://hello.127.0.0.1.nip.io:8080/){target="_blank"}

## Cleaning up

1. Remove Gefyra's components from the cluster with

```sh
gefyra down
```

2. Remove the locally running Kubernetes cluster with

```sh
kind delete cluster
```
